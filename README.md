# Winning the Space Race with Data Science

This repository contains the fininal project for the IBM Data Science Capstone, part of the IBM Data Science Professional Certificate. The project focuses on analyzing SpaceX Falcon 9 launches using data science methodologies, with the goal of predicting launch outcomes based on various factors.

## Project Overview

This project analyzes Falcon 9 launch data, aiming to predict the success of booster landings. By using various data science techniques, including exploratory data analysis (EDA), data wrangling, visual analytics, and predictive modeling, we provide insights into key factors influencing launch outcomes.

## Data Collection

We leveraged the SpaceX API and other publicly available data sources, including Wikipedia, to extract data about Falcon 9 launches. The collected data was used to examine historical trends and predict future launch outcomes.

## Methodology

1. **Data Collection & Wrangling**: We gathered relevant data using the SpaceX API and complemented it with additional launch records from Wikipedia.
2. **Exploratory Data Analysis**: Visualization and SQL queries were used to analyze data patterns, relationships, and factors influencing launch success.
3. **Visual Analytics**: Folium was used for interactive geographic analysis of launch sites and outcomes.
4. **Predictive Modeling**: We built classification models to predict booster landing success using several machine learning techniques.

## Results

- Insights gained from data visualizations and EDA.
- Interactive visual analytics showing launch site outcomes.
- Predictive models achieving high accuracy in determining booster landing success.
